# bratishka

Голосовой робот-собеседник для Claude Code. Мод открывает отдельное окно с роботом из частиц, и тот озвучивает ответы Claude локальным голосом Silero. Пока окно открыто, Claude отвечает в манере робота: по-свойски, с юмором и матом. Код, коммиты и документация при этом остаются нормальными.

Говорить с роботом можно голосом через [Handy](https://github.com/cjpais/Handy) или текстом в окне. Стоит начать говорить, и робот замолкает, так что он не перебивает.

## Что умеет

- **Окно с роботом.** WebGL-фигура из частиц собирается при открытии и меняет состояние: слушает, думает, говорит. Слушая, реагирует на микрофон, пока окно активно.
- **Озвучка ответов.** Четыре уровня: одна фраза, два-три предложения, подробный пересказ или весь текст. Весь текст озвучивается прямо по ходу ответа, предложение за предложением. Короткие уровни пересказывает модель Haiku.
- **Голосовой ввод.** То, что Handy вставил в окно, уходит в Claude как обычный запрос.
- **Перебивание.** Сервер следит за логом Handy. Как только начинается запись, робот замолкает, а остаток ответа, пришедший во время записи, не озвучивает.
- **Монитор.** Панель слева показывает кардиограмму по состоянию сессии, последние вызовы инструментов, свободный контекст, лимиты и стоимость.
- **Персона.** Пока окно открыто и принадлежит текущей сессии, к системному промпту добавляется раздел с манерой общения робота.

## Требования

- macOS. Окно открывается на самом большом из дополнительных экранов, если он есть.
- Google Chrome. Робот живёт в отдельном окне-приложении со своим профилем.
- Claude Code с поддержкой модов (проверено на 2.1.299).
- Python 3.
- Голос робота — локальный сервер Silero TTS [bratishka-golos](https://github.com/fomin-aleksey/bratishka-golos), установленный в `~/.claude/mods/silero-tts`. Это отдельный репозиторий, порядок установки описан в его README. Робот запускает сервер сам, когда тот нужен.
- [Handy](https://github.com/cjpais/Handy) — по желанию, для голосового ввода и перебивания.

## Установка

1. Склонируйте репозиторий в папку модов:

   ```bash
   git clone https://github.com/fomin-aleksey/bratishka ~/.claude/mods/robot
   ```

2. Добавьте путь в `env` файла `~/.claude/settings.json` (несколько модов разделяются двоеточием):

   ```json
   {
     "env": {
       "CLAUDE_CODE_PLUGIN_DIRS": "~/.claude/mods/robot"
     }
   }
   ```

3. Перезапустите сессию Claude Code и выполните `/robot`.

При первом запуске мод создаёт `~/.claude/commands/robot.md`, чтобы `/robot` с самого начала был в списке команд новых сессий.

## Управление

| Клавиша | Действие |
|---|---|
| `T` | показать или спрятать панель с текстом |
| `V` | показать или спрятать монитор |
| `F` | во весь экран |
| `Esc` | замолчать |

Окно принадлежит той сессии, которая последней выполнила `/robot`. Только она получает запросы из окна, и только её ответы робот озвучивает.

Параметры адреса для демонстрации и отладки: `?intro=0` — без сборки при открытии, `?demo=speak|loud|think|mic|cycle` — изображать речь, раздумье или голос человека, `?panel=0|1` и `?monitor=0|1` — панели.

## Устройство

- `hooks/register.ts` — мод: команда `/robot`, запуск сервера и окна, передача запросов, ответов и вызовов инструментов.
- `hooks/voice.ts`, `hooks/speech.ts` — нарезка ответа на фразы для озвучки и пересказ.
- `hooks/persona.ts` — манера общения робота.
- `runtime/server.py` — локальный сервер окна на `127.0.0.1:47219`: очередь речи, события для окна, слежение за Handy.
- `runtime/*.js` — окно: сцена, фигура, монитор, интерфейс.

Запросы из окна попадают в сессию Claude, которая может работать без подтверждений. Поэтому эти эндпоинты требуют токен из `runtime/.token` (права 600), сервер слушает только `127.0.0.1` и проверяет заголовки `Host` и `Origin`.
